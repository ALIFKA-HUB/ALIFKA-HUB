# Complex GitHub Profile Implementation Plan

Berdasarkan *tech stack* yang lu sebutin (JavaScript, React, Node.js, Figma, Antigravity, Gemini, Claude) dan hobi lu, gua menyimpulkan bahwa role yang paling cocok dan keren buat lu saat ini adalah: **AI-Empowered Full-Stack Developer** atau **Creative Web Developer**. Lu punya kombinasi antara kemampuan *engineering* (JS, Node, React), *design* (Figma), dan *AI leveraging* (Gemini, Claude, Antigravity).

Berikut adalah rencana implementasi (Implementation Plan) untuk membuat profil GitHub lu jadi sangat kompleks, dinamis, dan terlihat sangat profesional.

## User Review Required

> [!IMPORTANT]
> **GitHub Username**
> Untuk membuat *repository* spesial ini, lu harus membuat repositori dengan nama yang **sama persis** dengan *username* GitHub lu (misal: jika username lu `alifkahub`, maka nama repository-nya juga `alifkahub`). Apakah lu sudah punya repository ini?

> [!WARNING]
> **GitHub Actions & Dynamic Stats**
> Plan ini mencakup penggunaan *Dynamic Stats* (seperti GitHub Snake Animation atau Wakatime). Apakah lu setuju untuk menggunakan GitHub Actions untuk meng-update animasi profil lu secara otomatis setiap hari?

## Open Questions

> [!CAUTION]
> 1. Apa *username* GitHub lu dan Instagram lu? (Agar gua bisa langsung masukin *link*-nya ke kode).
> 2. Untuk *fun fact*, gua merencanakan ini: *"I code with AI on one screen, play music on the other, and probably think about sports or hanging out when I'm away from keyboard."* Gimana menurut lu?
> 3. Mau pakai tema warna apa? (Contoh: *Dark Mode* dengan aksen Neon/Cyberpunk, atau Minimalis Monokrom?)

## Proposed Changes

Kita akan membagi profil ini menjadi beberapa komponen yang saling melengkapi di dalam satu file `README.md`.

### Component 1: Dynamic Hero Section
- Menggunakan animasi teks berjalan (Typing SVG) yang memperkenalkan lu sebagai *AI-Empowered Full-Stack Developer*.
- *Banner* visual atau GIF estetik yang nyambung dengan *vibe* coding, musik, dan olahraga.

### Component 2: About Me & Fun Fact
- Deskripsi singkat tentang diri lu.
- Fun fact yang menggabungkan hobi nongkrong, musik, olahraga, dan interaksi lu sama AI.

### Component 3: Tech Stack & Tools Showcase
Menampilkan *badges* (ikon yang rapi) untuk:
- **Frontend & Design:** JavaScript, React, Figma.
- **Backend:** Node.js.
- **AI & Productivity:** Antigravity, Gemini, Claude, GitHub.

### Component 4: Dynamic GitHub Stats
- Menambahkan **GitHub Stats Card** (menampilkan total *stars*, *commits*, *PRs*).
- Menambahkan **Top Languages Card** (menampilkan bahasa pemrograman yang paling sering lu pakai).
- *(Opsional)* **GitHub Contribution Snake Animation**: Animasi ular memakan *commit history* lu yang di-generate otomatis pakai GitHub Actions.

### Component 5: Let's Connect
- Tombol elegan untuk Instagram dan Email.

## Verification Plan

### Manual Verification
- Gua akan meng-generate kode `README.md` secara utuh.
- Lu bisa mencobanya dengan menempelkan (paste) kode tersebut di `README.md` pada repositori profil GitHub lu dan melihat *preview*-nya secara langsung.
- Kita akan menyesuaikan (tweak) desain *badges* dan warna *stats* sampai lu puas dengan estetikanya.
